awg-mesh — пакетные репозитории

Подписанные репозитории пакета meshd (AmneziaWG mesh-сеть): apt для Debian/Ubuntu и apk для OpenWrt 25.12+. Установка и обновление — штатными apt/apk.

Debian / Ubuntu (apt)

sudo install -d -m 0755 /etc/apt/keyrings
sudo wget -qO /etc/apt/keyrings/awg-mesh.asc \
  https://tumour.github.io/awg-mesh/debian/meshd-archive-keyring.asc
echo "deb [signed-by=/etc/apt/keyrings/awg-mesh.asc] https://tumour.github.io/awg-mesh/debian stable main" \
  | sudo tee /etc/apt/sources.list.d/awg-mesh.list
sudo apt-get update && sudo apt-get install meshd

Обновление потом — sudo apt-get update && sudo apt-get install --only-upgrade meshd. Арки: amd64, arm64.

OpenWrt 25.12+ (apk)

WRT_VER=$( . /etc/openwrt_release; echo "${DISTRIB_RELEASE%%-*}" | cut -d. -f1-2 )
echo "https://tumour.github.io/awg-mesh/openwrt/${WRT_VER}/$(cat /etc/apk/arch)/packages.adb" \
  > /etc/apk/repositories.d/awg-mesh.list
wget https://tumour.github.io/awg-mesh/openwrt/awg-mesh-apk.rsa.pub \
  -O /etc/apk/keys/awg-mesh-apk.rsa.pub
apk update && apk add --latest meshd

Если GitHub заблокирован (зеркало jsDelivr)

Замените в командах выше хост tumour.github.io/awg-mesh на cdn.jsdelivr.net/gh/tumour/awg-mesh@gh-pages.
